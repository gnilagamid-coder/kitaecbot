# Установка с нуля — подробная инструкция

Гайд для тех, кто никогда не работал с сервером. Если делать по шагам и ничего не
пропускать, весь путь занимает 20–30 минут, из которых ~5 минут — сама установка,
остальное регистрации и ожидание.

Ничего платить за домен не нужно: используем бесплатный **DuckDNS**.

---

## Сначала — важное про «вебхук»

Многие гайды по ботам требуют настраивать вебхук. **Здесь этого делать не нужно.**

Наш бот работает через *long polling* — он сам раз в 30 секунд спрашивает у Telegram
«есть новости?». Это значит: никаких вебхуков, никаких `setWebhook`, бот заводится
сразу после установки.

Домен и HTTPS всё равно нужны, но по другой причине: **Telegram открывает Mini App
только по `https://`**. Обычный IP-адрес или `http://` он не примет. Именно за этим
нам DuckDNS и бесплатный сертификат.

Итого нужны две вещи:
1. Бот (токен) — для уведомлений и кнопки «Открыть магазин».
2. Домен с HTTPS — чтобы витрина открывалась внутри Telegram.

---

## ⚠️ На Netlify / Vercel это не поставить

Если вы уже пробовали залить проект на Netlify и получили **HTTP 502** — так и
должно быть, это не ваша ошибка в настройках.

Магазин версии 2.0 — обычный сервер, который работает постоянно: он хранит товары
и фото в файлах и держит бота на связи с Telegram. Netlify и Vercel запускают код
короткими вспышками по запросу и не хранят файлы между вызовами, поэтому там не
живут ни бот, ни каталог.

Нужен именно VPS — это дешевле, чем кажется, и весь процесс расписан ниже.

## Что понадобится

| Что | Где взять | Сколько стоит |
|---|---|---|
| Аккаунт Telegram | уже есть | — |
| VPS с Debian 12 или Ubuntu 24.04 | любой хостинг | от ~150–300 ₽/мес |
| Домен | duckdns.org | бесплатно |
| Сертификат HTTPS | Let's Encrypt | бесплатно, ставится сам |

Требования к VPS минимальные: **1 ядро, 1 ГБ RAM, 10 ГБ диска** — этого хватает с
запасом. При заказе обязательно выберите чистый **Debian 12** (или Ubuntu 24.04),
без панелей управления вроде ISPmanager.

## Шаг 1. Создаём бота и получаем токен

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Введите имя бота — как он будет подписан в чатах, например `Мой магазин`.
4. Введите username — обязательно заканчивается на `bot`, например `my_shop_2024_bot`.
5. BotFather пришлёт строку вида:

```
123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
```

Это **токен**. Скопируйте его в заметки — он понадобится на шаге 5.

> ⚠️ Токен — это полный доступ к боту. Никому его не показывайте, не выкладывайте
> в чаты и на скриншоты. Если засветили — `/revoke` в BotFather, и получите новый.

Пока не закрывайте BotFather, вернёмся к нему на шаге 7.

---

## Шаг 2. Узнаём свой Telegram ID

Понадобится, чтобы заказы приходили именно вам.

1. Найдите своего бота по username, которое придумали (`@my_shop_2024_bot`).
2. Нажмите **Start** и отправьте ему `/start`.

Этого пока достаточно. Число мы получим позже, на шаге 8, когда бот уже будет запущен.

> ⚠️ Написать боту `/start` **обязательно**. Telegram запрещает боту писать первым
> тому, кто с ним не общался. Если пропустить — уведомления о заказах просто не придут,
> причём без всякой ошибки.

## Шаг 3. Заказываем VPS

Подойдёт любой провайдер: Timeweb, Beget, Selectel, RuVDS, Aeza, Hetzner, Contabo и т. д.

При заказе:
- ОС: **Debian 12** (если нет — Ubuntu 24.04);
- тариф: самый дешёвый, 1 CPU / 1 GB RAM;
- локация: ближе к покупателям (для РФ — Москва или Европа).

После оплаты хостинг пришлёт письмо или покажет в панели:

```
IP: 203.0.113.45
Пользователь: root
Пароль: xxxxxxxx
```

Запишите эти три строки. **IP-адрес** понадобится дальше постоянно.

## Шаг 4. Подключаемся к серверу

### Windows 10/11

Откройте меню «Пуск», наберите `PowerShell`, запустите. В окне введите (подставьте свой IP):

```
ssh root@203.0.113.45
```

При первом подключении спросит:

```
Are you sure you want to continue connecting (yes/no)?
```

Напечатайте `yes` и нажмите Enter.

Дальше запросит пароль. **Вводите пароль вслепую** — символы не отображаются, это
нормально, просто наберите и нажмите Enter. Удобнее скопировать пароль и вставить
правой кнопкой мыши.

### macOS / Linux

Откройте «Терминал» и та же команда:

```
ssh root@203.0.113.45
```

### Как понять, что подключились

Строка приглашения сменится на что-то вроде:

```
root@vps12345:~#
```

Теперь всё, что вы печатаете, выполняется **на сервере**, а не на вашем компьютере.

## Шаг 5. Делаем бесплатный домен на DuckDNS

1. Откройте [duckdns.org](https://www.duckdns.org).
2. Нажмите **Sign in with Google** (или GitHub / Twitter / Reddit) — регистрации нет,
   вход через существующий аккаунт.
3. Наверху страницы вы увидите строку **token** — длинную строку вида
   `a7b1c9d2-3e4f-5a6b-7c8d-9e0f1a2b3c4d`. Скопируйте, пригодится в конце шага.
4. В поле **sub domain** впишите желаемое имя, например `myshop2024`, и нажмите
   **add domain**.
5. Появится строка `myshop2024.duckdns.org`. В поле **current ip** впишите IP вашего
   сервера (`203.0.113.45`) и нажмите **update ip**.

Ваш домен: **`myshop2024.duckdns.org`** — запишите его.

### Проверяем, что домен заработал

Вернитесь в окно SSH и выполните:

```
ping -c 3 myshop2024.duckdns.org
```

В ответе должен быть ваш IP:

```
PING myshop2024.duckdns.org (203.0.113.45) 56(84) bytes of data.
64 bytes from 203.0.113.45: icmp_seq=1 ttl=64 time=0.028 ms
```

Если IP другой или пишет `Name or service not known` — подождите 2–3 минуты и
повторите. DNS обновляется не мгновенно. **Не переходите к следующему шагу, пока
здесь не появится правильный IP** — иначе не выпустится сертификат.

### Автообновление IP (необязательно)

У VPS обычно постоянный IP, и этот блок можно пропустить. Но если хостинг меняет IP
при перезагрузке, настройте автообновление — одна команда (подставьте свои
поддомен и токен):

```
(crontab -l 2>/dev/null; echo '*/5 * * * * curl -s "https://www.duckdns.org/update?domains=myshop2024&token=ВАШ_ТОКЕН&ip=" >/dev/null') | crontab -
```

Теперь сервер сам каждые 5 минут сообщает DuckDNS свой актуальный адрес.

## Шаг 6. Загружаем магазин на сервер и ставим

### 6.1. Копируем файлы

Проще всего — через GitHub. Если папка с магазином уже лежит в вашем репозитории,
выполните на сервере:

```
apt update && apt install -y git && git clone ВАШ_РЕПОЗИТОРИЙ /root/tg-shop
```

**Если репозитория нет** и файлы лежат у вас на компьютере — загрузим напрямую.
Откройте **второе** окно PowerShell/Терминала (не то, где SSH!) и выполните, подставив
свой путь к папке и IP:

```
scp -r "C:\Users\Alex\Downloads\122413234234234423234" root@203.0.113.45:/root/tg-shop
```

Введите пароль от сервера. Дождитесь окончания копирования.

> Тем, кому удобнее мышкой: подойдёт бесплатная программа **WinSCP** (Windows) или
> **Cyberduck** (macOS) — подключаетесь по протоколу SFTP с теми же IP, логином
> `root` и паролем, и перетаскиваете папку в `/root/tg-shop`.

### 6.2. Запускаем установщик

Вернитесь в окно с SSH и выполните две команды по очереди:

```
cd /root/tg-shop
```

```
bash install.sh
```

Установщик задаст **четыре вопроса**:

| Вопрос | Что вводить |
|---|---|
| `Токен бота от @BotFather` | токен с шага 1 |
| `Домен` | `myshop2024.duckdns.org` — **без** `https://` и без `/` в конце |
| `Пароль в админку` | нажмите **Enter**, чтобы сгенерировался надёжный |
| `Внутренний порт [3000]` | нажмите **Enter** |

Дальше он всё сделает сам: поставит Node.js, создаст служебного пользователя,
настроит автозапуск, поднимет nginx и выпустит HTTPS-сертификат. Это занимает 2–4
минуты, по экрану будут бежать зелёные строки.

В конце появится рамка:

```
════════════════════════════════════════════════
  Готово.

  Витрина:  https://myshop2024.duckdns.org/
  Админка:  https://myshop2024.duckdns.org/admin.html
  Пароль:   K3xR9mQp2wLnZ7vB4tYs
════════════════════════════════════════════════
```

**Сразу скопируйте пароль в заметки.** Второй раз он показан не будет.

### Проверяем

Откройте в браузере `https://myshop2024.duckdns.org/` — должна открыться витрина с
надписью «Каталог пока пуст». Замочек в адресной строке — значит HTTPS работает.

## Шаг 7. Подключаем витрину к Telegram

Возвращаемся в [@BotFather](https://t.me/BotFather).

1. Отправьте `/newapp`.
2. Выберите своего бота из списка.
3. **Title** — название приложения, например `Магазин`.
4. **Description** — короткое описание, например `Каталог и заказы`.
5. **Photo** — обложка 640×360. Если картинки под рукой нет, отправьте `/empty` —
   добавите позже командой `/editapp`.
6. **GIF** — демо-ролик, тоже необязателен: отправьте `/empty`.
7. **Web App URL** — вставьте адрес витрины **целиком, со слэшем на конце**:

```
https://myshop2024.duckdns.org/
```

8. **Short name** — короткое имя латиницей, от 3 до 30 символов, например `shop`.

BotFather пришлёт ссылку вида:

```
https://t.me/my_shop_2024_bot/shop
```

Это и есть ссылка на ваш магазин. Скопируйте — понадобится на шаге 8.

### Добавляем кнопку в меню бота

Чтобы магазин открывался кнопкой рядом с полем ввода:

1. `/setmenubutton` → выберите бота.
2. Отправьте ту же ссылку `https://t.me/my_shop_2024_bot/shop`.
3. Введите надпись на кнопке, например `Магазин`.

Откройте чат с ботом — внизу появилась кнопка. Нажмите: должна открыться витрина
прямо внутри Telegram.

---

## Шаг 8. Настраиваем магазин

Откройте `https://myshop2024.duckdns.org/admin.html`, введите пароль из шага 6.

### 8.1. Уведомления — сделайте это первым

Без этого шага заказы до вас не дойдут.

1. Напишите своему боту команду `/id` — он ответит вашим числовым ID.
2. В админке откройте вкладку **Уведомления**.
3. Нажмите **+ Добавить получателя** и вставьте это число.
4. Нажмите внизу **Сохранить настройки**.
5. Нажмите **Отправить тестовое уведомление**.

Должно прийти сообщение в Telegram и появиться зелёная строка `✓ Отправлено`.

Если пришла красная ошибка `bot can't initiate conversation with a user` — вы не
написали боту `/start` (шаг 2). Напишите и повторите тест.

### 8.2. Остальное

| Вкладка | Что заполнить |
|---|---|
| **Бренд** | название магазина, эмодзи или логотип |
| **Тема** | выберите пресет оформления — цвета подхватятся сразу |
| **Продажи** | режим работы и ссылка на менеджера (ваш `@username`) |
| **Канал** | вставьте ссылку мини-аппа с шага 7 — заработает публикация товаров |
| **Товары** | добавьте первый товар: фото, название, цена |

После каждой правки внизу появляется кнопка **Сохранить настройки** — не забывайте
нажимать.

### 8.3. Проверяем целиком

Откройте магазин в Telegram, добавьте товар в корзину, оформите заказ. Вам в Telegram
должно прийти уведомление со списком товаров и контактами покупателя. Если пришло —
магазин полностью рабочий.

## Переезд на другой сервер

Нужен, если текущий хостер режет Telegram (проверяется командой из раздела
«Если что-то пошло не так»). Товары, настройки и фотографии переносятся целиком,
заново ничего заполнять не придётся.

**Шаг 1.** На старом сервере соберите архив с данными:

```
tar czf ~/shop-data.tgz -C /opt/tg-shop data
```

**Шаг 2.** Скачайте его к себе на компьютер — команду выполняйте **на своём
компьютере**, подставив IP старого сервера:

```
scp root@СТАРЫЙ_IP:~/shop-data.tgz .
```

**Шаг 3.** Закажите VPS у зарубежного провайдера (Hetzner, Contabo, Aeza и т.п.),
Debian 12 или Ubuntu 24.04. Пройдите шаги 4–6 этой инструкции: подключитесь,
загрузите файлы магазина, запустите `bash install.sh`. Домен можно указать тот же —
только не забудьте на duckdns.org поменять IP на новый.

**Шаг 4.** Залейте данные на новый сервер — с вашего компьютера:

```
scp shop-data.tgz root@НОВЫЙ_IP:~/
```

**Шаг 5.** На новом сервере распакуйте и перезапустите:

```
tar xzf ~/shop-data.tgz -C /opt/tg-shop && chown -R tgshop:tgshop /opt/tg-shop/data && systemctl restart tg-shop
```

**Шаг 6.** Проверьте, что связь появилась:

```
curl -sS -m 10 https://api.telegram.org | head -c 100
```

Должен прийти JSON-ответ, а не таймаут. После этого откройте админку → вкладка
**Обзор** → «Диагностика»: строка «Связь с Telegram» должна стать зелёной.

**Шаг 7.** В BotFather поменяйте URL мини-аппа, если сменили домен:
`/myapps` → выбрать приложение → `Edit Web App URL`.

Старый сервер можно удалять только после того, как на новом прошла проверка из
шага 6 и пришло тестовое уведомление.

## Промокоды

Админка → вкладка **Промокоды** → включить «Принимать промокоды» → «+ Добавить код».

У каждого кода настраивается:

| Поле | Что значит |
|---|---|
| **Код** | То, что вводит покупатель. Регистр и пробелы не важны — `sale20` и `SALE 20` найдут `SALE20` |
| **Тип** | «Процент» — скидка в % от суммы. «Сумма» — фиксированная скидка |
| **Скидка** | Число: 20 для 20 % или 500 для 500 ₽ |
| **Заказ от** | Минимальная сумма. 0 — без ограничения |
| **Осталось применений** | Пусто — без ограничения. Число уменьшается с каждым заказом |
| **✓ / ○** | Быстро выключить код, не удаляя |

Поле для ввода появится в форме заказа. Скидка считается **на сервере** — подделать
её из браузера нельзя. Сами коды на витрину не отдаются, поэтому подобрать их
перебором через API тоже не получится.

## Обновление до новой версии

Когда магазин уже работает и нужно просто подтянуть свежий код:

```
cd /root/tg-shop && bash update.sh
```

Скрипт сам скачает обновления, сделает резервную копию товаров, перезапустит
магазин и проверит, что он поднялся. Пароль админки, токен бота, товары и
фотографии остаются на месте — он их не трогает.

> Не запускайте для обновления `install.sh` — он заново задаст все вопросы и
> будет перевыпускать сертификат. Он нужен только для первой установки или
> когда меняется домен.

После обновления обновите страницу магазина с очисткой кэша: **Ctrl+F5**
(Windows) или **Cmd+Shift+R** (Mac).

## Полезные команды

Все выполняются на сервере, в окне SSH.

Посмотреть, работает ли магазин:

```
systemctl status tg-shop
```

Зелёное `active (running)` — всё хорошо. Выйти из просмотра — клавиша `q`.

Перезапустить:

```
systemctl restart tg-shop
```

Смотреть логи в реальном времени (полезно, если что-то сломалось):

```
journalctl -u tg-shop -f
```

Выйти из логов — `Ctrl + C`.

Сделать резервную копию (товары, настройки, фото):

```
tar czf ~/backup-$(date +%F).tgz -C /opt/tg-shop data
```

Забрать копию себе на компьютер — выполнить **на своём компьютере**, не на сервере:

```
scp root@203.0.113.45:~/backup-*.tgz .
```

## Если что-то пошло не так

**Установщик написал «Certbot не смог выпустить сертификат»**
Домен ещё не «доехал» до сервера. Проверьте `ping -c 3 ваш-домен.duckdns.org` — там
должен быть IP сервера. Когда совпадёт, выпустите сертификат вручную:

```
certbot --nginx -d myshop2024.duckdns.org
```

**Витрина не открывается, браузер пишет «сайт недоступен»**
Проверьте, запущен ли сервис: `systemctl status tg-shop`. Если `failed` — посмотрите
причину в `journalctl -u tg-shop -n 50`.

**Telegram пишет о недоверенном сертификате при открытии Mini App**
Сертификат не выпустился. См. первый пункт.

**Уведомления о заказах не приходят**
Три причины по частоте: не написали боту `/start`; вписали не тот ID (проверьте
командой `/id`); не нажали «Сохранить настройки» после добавления получателя.

**Забыли пароль от админки**
Посмотрите его на сервере:

```
grep ADMIN_TOKEN /opt/tg-shop/.env
```

**Хочу сменить пароль админки**
Откройте файл: `nano /opt/tg-shop/.env`, поправьте строку `ADMIN_TOKEN=`, сохраните
(`Ctrl+O`, Enter, `Ctrl+X`) и перезапустите: `systemctl restart tg-shop`.

**Бот не отвечает на `/start`**
Проверьте логи: `journalctl -u tg-shop -n 30`. Если там `не удалось авторизоваться` —
неверный токен в `/opt/tg-shop/.env`, поправьте и перезапустите.

**«Нет связи с api.telegram.org» при любом действии бота**
Сервер физически не может достучаться до Telegram. Вебхук здесь не поможет: исходящие
запросы всё равно идут туда же. Проверьте прямо на сервере:

```
curl -sS -m 10 https://api.telegram.org | head -c 200
```

- Ответ пришёл → проблема была в IPv6, версия 2.0 уже форсирует IPv4, просто
  перезапустите: `systemctl restart tg-shop`.
- Висит или «Connection timed out» → ваш хостер режет Telegram. Так бывает у части
  российских провайдеров. Варианты: сменить хостинг на зарубежный, либо поднять
  прокси и указать его в `.env`:

```
TELEGRAM_API_BASE=https://ваш-прокси
```

Точную причину показывает админка: вкладка **Обзор** → «Диагностика».

## Минимальная безопасность

Стоит потратить пять минут после установки.

Включить файрвол — оставить только SSH и веб:

```
apt install -y ufw && ufw allow OpenSSH && ufw allow 'Nginx Full' && ufw --force enable
```

Сменить пароль root на свой:

```
passwd
```

И не давайте пароль от админки посторонним — внутри неё нет ограниченных прав, она
даёт полный доступ к магазину.
